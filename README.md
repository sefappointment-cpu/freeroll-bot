# Бот паролей на покерные фрироллы

Каждые 5 минут забирает расписание с freerollpass.com и публикует в Telegram-канал фрироллы, у которых есть пароль. Каждый турнир публикуется один раз; уже опубликованные хранятся в `state.json`.

Пример поста:

```
🇺🇸 TODAY'S POKER FREEROLLS
🃏 Tournament: Stake Poker – PokerWired $250 GTD
🕒 Time: 4:00 PM ET
💰 Prize Pool: $250
🔑 Password: bigpapa        ← нажатием копируется
♠️ Good luck at the tables!
```

Время пересчитывается в ET (Нью-Йорк, с учётом летнего времени). Если турнир завтра по ET, заголовок будет TOMORROW'S. Часовой пояс меняется переменными `POST_TZ` и `POST_TZ_LABEL`.

## Как работает

- Сайт подгружает таблицу внутренним AJAX-запросом; бот делает тот же запрос и проходит по всем страницам списка.
- Время приходит сразу в часовом поясе Лиссабона.
- Фрироллы без пароля пропускаются.
- Если на сайте написано «пароль будет доступен в 19:50», бот ничего не публикует и подхватит пароль при одном из следующих запусков.
- Пост выходит за 30 минут до старта турнира. Если пароль появился позже (например, за 10 минут) или запуск задержался, пост выйдет сразу, пока открыта регистрация. Турниры с закрытой регистрацией не публикуются.
- GitHub запускает расписание с задержкой, обычно от нескольких минут, поэтому пост может выйти, например, за 25 минут, а не ровно за 30.

## Установка

1. **Канал.** Создайте новый канал в Telegram.
2. **Бот.** В @BotFather отправьте `/newbot`, получите токен. Добавьте бота в администраторы канала с правом публикации сообщений.
3. **Репозиторий.** Создайте новый **публичный** репозиторий на GitHub и загрузите туда все файлы из этой папки, включая `.github/workflows/freerolls.yml`.
4. **Секреты.** В репозитории: Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_CHANNEL` — `@имя_канала` (для приватного канала — числовой id вида `-100…`)
5. **Права Actions.** Settings → Actions → General → Workflow permissions → «Read and write permissions».
6. **Первый запуск.** Вкладка Actions → Freeroll passwords → Run workflow. Дальше он запускается сам.

Почему публичный: бот запускается каждые 5 минут, это около 8 600 запусков в месяц. Для публичных репозиториев Actions бесплатны без ограничений, а в приватных бесплатно только 2 000 минут в месяц, и их хватит примерно на неделю. Секреты (токены) в публичном репозитории не видны.

## Настройки

В `.github/workflows/freerolls.yml`, блок `env`:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `POST_AHEAD_MINUTES` | `30` | За сколько минут до старта публиковать пост |
| `SKIP_DEPOSIT_ONLY` | `0` | `1` — не публиковать фрироллы только для депозитчиков |

Проверить локально без публикации:

```
pip install -r requirements.txt
python bot.py --dry-run
```

## Учёт переходов (ссылки на румы)

Название рума в посте — ссылка вида `https://freeroll-go.<ваше-имя>.workers.dev/r/stakepoker?p=321148`. Сервис засчитывает переход и сразу перекидывает человека на сайт рума. Сохраняется: время, рум, турнир, страна, город, тип устройства. IP-адреса не хранятся; «уникальные» считаются по хэшу, который меняется каждые сутки.

Статистика: `https://freeroll-go.<ваше-имя>.workers.dev/stats?key=<STATS_KEY>` — переходы по румам, странам, городам, устройствам, дням и лучшие посты, за сутки / 7 / 30 дней / всё время.

Работает на Cloudflare Workers, бесплатный тариф (до 100 000 переходов в сутки).

### Установка (один раз)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно).
2. **Workers & Pages** → откройте раздел один раз, Cloudflare попросит выбрать поддомен `*.workers.dev` — выберите любое имя.
3. **Storage & Databases → D1 → Create database**, имя `freeroll-clicks`. Скопируйте **Database ID** и вставьте его в `tracker/wrangler.toml` вместо `ВСТАВЬТЕ_ID_БАЗЫ`. Таблицу создавать не нужно, сервис сделает это сам.
4. **Account ID** — на главной странице аккаунта (правая колонка) или в Workers & Pages.
5. **API-токен**: значок профиля → My Profile → API Tokens → Create Token → шаблон **Edit Cloudflare Workers** → добавьте строку разрешений **Account · D1 · Edit** → Create.
6. В репозитории GitHub, Settings → Secrets and variables → Actions → **Secrets**, добавьте:
   - `CLOUDFLARE_API_TOKEN` — токен из шага 5
   - `CLOUDFLARE_ACCOUNT_ID` — из шага 4
   - `STATS_KEY` — любой длинный пароль, им открывается статистика
7. Actions → **Deploy click tracker** → Run workflow. В логе появится адрес вида `https://freeroll-go.<имя>.workers.dev`.
8. Там же, но на вкладке **Variables**, создайте переменную `TRACKER_URL` с этим адресом. С этого момента посты пойдут со ссылками.

### Список румов

Адреса румов — в `rooms.json` (ключ — как рум называется в адресе на freerollpass.com, например `freerollpass.com/stakepoker` → `stakepoker`). После правки и коммита сервис переразвернётся сам. Румы, которых нет в списке, публикуются обычным текстом без ссылки. Сейчас без ссылки: BC Poker, Betplay Poker, PokerOK, PokerKing, Coral, Ladbrokes, Betfred и сеть iPoker — допишите их адреса, если нужно. Адреса в списке стоит один раз прокликать: я не смог проверить их все автоматически.

Если позже появятся свои партнёрские ссылки, просто замените адрес рума в `rooms.json` — статистика сохранится.

## Если перестало работать

- **«Сайт вернул не JSON» в логах Actions.** Сайт стоит за Cloudflare, и он может начать блокировать серверы GitHub. Тогда бота нужно запускать с другого сервера (VPS или домашний компьютер по расписанию, через cron), код менять не придётся.
- **Посты перестали появляться, ошибок нет.** Скорее всего, сайт поменял вёрстку, и нужно поправить функцию `parse()` в `bot.py`.
- **GitHub отключил расписание.** В публичных репозиториях Actions по расписанию выключаются после 60 дней без коммитов. Здесь бот сам коммитит `state.json`, так что обычно это не происходит.
